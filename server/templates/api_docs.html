API 文档

{% if current_user.is_authenticated %} 在设置页生成 API Token {% endif %}

除文档页外，所有接口都需要 X-API-Key: <key> 请求头鉴权（也兼容 Authorization: Bearer <key>）。Key 在 设置 → 开发者 API 生成，用户和管理员账号都能使用，权限与账号一致（管理员 Key 拥有管理员权限）。

快速开始
# 1. 设置页生成 Key（记为 $KEY）

# 2. 提交推理任务（multipart 上传音频）
curl -X POST https://你的域名/api/v1/inference \
  -H "X-API-Key: $KEY" \
  -F "config_id=1" \
  -F "audio=@song.wav"
# {"created": 1, "skipped": []}

# 3. 查询任务状态
curl https://你的域名/api/v1/tasks/42 \
  -H "X-API-Key: $KEY"
# {"id":42,"status":"done","pct":100,"has_result":true,...}

# 4. 下载结果
curl -o result.wav https://你的域名/api/v1/tasks/42/result \
  -H "X-API-Key: $KEY"
方法路径说明
POST/api/v1/inference提交推理任务（multipart: config_id + audio 文件，可传多个）
GET/api/v1/tasks/<id>查询单个任务状态
GET/api/v1/tasks我的任务列表（可选 ?status=done 筛选）
GET/api/v1/tasks/<id>/result下载推理结果文件
GET/api/v1/models我可用的模型列表
GET/api/v1/configs我的推理配置列表（含参数）
GET/api/v1/me我的信息 + 配额 + 今日用量
GET/api/v1/system系统状态（daemon/队列/调度暂停/统计）
WSws://host:5001/api/v1/ws/stream实时变声（麦克风→变声→回放），见下方协议
实时变声 WebSocket

准实时变声（约 1~2s 延迟）。完整协议见 docs/realtime_vc.md

连接: ws://host:5001/api/v1/ws/stream?api_key=KEY
上行: 44.1kHz 单声道 float32 PCM（麦克风块，建议 20~40ms）
下行: 44.1kHz 单声道 float32 PCM（变声后）
控制: 文本 JSON
  {"op":"init","config_id":1,"chunk_seconds":0.363,...} → {"op":"ready"}
  {"op":"ping"} → {"op":"pong"}
  {"op":"stop"} / {"op":"close"}
限制: 全局 1 会话 · 无音频 60s 断连 · 单会话最长 30 分钟
任务状态枚举
  • pending 排队中 · claimed 已领取 · running 推理中 · done 完成 · failed 失败 · stopped 已停止
错误码
  • 401 token 缺失/无效/已撤销
  • 403 账号被禁用或资源不属于你
  • 404 任务/结果不存在
  • 429 触发限流或配额上限
  • 400 参数错误（如缺 config_id）
