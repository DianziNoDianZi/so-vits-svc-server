都有什么

so-vits-svc 本身是命令行工具，这个项目给它套了一层 Web 界面和任务管理。

推理换声

上传模型和音频提交任务，支持浅扩散（k_step）修音，进度在页面里实时显示。

️

训练 + 续训

数据集 zip 直接丢进队列。中途断了可以从 checkpoint 继续，主模型和扩散都支持。

随时停止试听

训练到一半想听效果，点停止，当前 checkpoint 自动存成模型，直接拿去推理。

Loss 曲线

G/D Loss 实时画成折线，验证集 loss 单独显示，方便判断是不是训过头了。

️

按任务清理

一个任务不要了，只清它自己的数据；可能误伤别的任务时会给提示。

文件管理

模型、配置、推理结果、数据集都能在网页里下载或删除，不用登服务器。

预训练页

ContentVec、NSF-HiFiGAN、底模 G_0/D_0、RMVPE 都走网页上传，省得 SSH 传文件。

邮件通知

训练完成、每 N 步、推理完成都会发邮件，SMTP 服务器自己在设置页填。

️

基本的防护

CSRF、登录限速、路径穿越检查、上传类型校验，这些都有。

大概怎么用

实际跑一圈大概是这样：

上传数据集

zip 打包上传，太短的片段会自动跳过

排队训练

填总步数等参数，底模自动加载

看 Loss 曲线

判断还在收敛还是已经过拟合

停止试听

满意就停，checkpoint 自动变成模型

训扩散

主模型好了直接进扩散训练

上传音频

提交推理，拿结果

怎么跑起来

Windows 装好后启动就行；Linux 有整合好的部署脚本，国内镜像。

# 安装（自动创建 venv + 安装 CPU/CUDA torch 与依赖）
install.bat

# 启动服务，浏览器访问 http://localhost:5000
start.bat
# 下载项目后执行（需 root；支持 NVIDIA CUDA / AMD ROCm / 纯 CPU，自动切换 PyTorch）
chmod +x deploy_linux.sh
sudo bash deploy_linux.sh

# 网络慢可跳过模型下载，部署后在网页"预训练"页补传
sudo bash deploy_linux.sh --skip-models

脚本会装 ffmpeg / libsndfile / cmake 等系统依赖，Miniconda 和 Python 3.9 走清华、阿里云镜像，不用手动配。

要准备哪些模型

推理必须有 ContentVec 和 NSF-HiFiGAN；训练的话底模 G_0 / D_0 建议放上。

文件大小获取方式
checkpoint_best_legacy_500.pt~180 MB部署脚本自动下载，或网页上传
nsf_hifigan/model + config~54 MB同上
G_0.pth + D_0.pth~400 MB网页上传（推荐）
rmvpe.pt 等编码器可选网页"预训练"页上传

文件大的话直接 scp 到 pretrain/ 目录，网页会自动识别。
