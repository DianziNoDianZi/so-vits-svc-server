使用流程

训练与推理两条主线，全部在浏览器里完成。

上传数据集

打包 zip 上传，自动过滤 2 秒以下的短片段

队列训练

设置总步数、auto_stop、编码器，底模自动加载

监控 Loss

看 train / 验证 loss 判断是否过拟合

随时停止试听

满意就停止，checkpoint 自动保存为模型

训练扩散

主模型训好后一键进入扩散训练

上传推理

上传音频 → 提交任务 → 下载结果

快速开始

Windows 一条命令安装；Linux 一键部署，自动走国内镜像。

# 安装（自动创建 venv + 安装 CPU/CUDA torch 与依赖）
install.bat

# 启动服务，浏览器访问 http://localhost:5000
start.bat
# 下载项目后执行（需 root；支持 NVIDIA CUDA / AMD ROCm / 纯 CPU，自动切换 PyTorch）
chmod +x deploy_linux.sh
sudo bash deploy_linux.sh

# 网络慢可跳过模型下载，部署后在网页"预训练"页补传
sudo bash deploy_linux.sh --skip-models

部署脚本会自动安装 ffmpeg / libsndfile / cmake 等系统依赖，并接入清华、阿里云国内镜像安装 Miniconda 与 Python 3.9 环境。

预训练模型

推理必需 ContentVec + NSF-HiFiGAN；训练底模 G_0 / D_0 可选但推荐。

文件大小获取方式
checkpoint_best_legacy_500.pt~180 MB部署脚本自动下载，或网页上传
nsf_hifigan/model + config~54 MB同上
G_0.pth + D_0.pth~400 MB网页上传（推荐）
rmvpe.pt 等编码器可选网页"预训练"页上传

大文件建议 scp 直接放入 pretrain/ 目录，网页会自动识别。
