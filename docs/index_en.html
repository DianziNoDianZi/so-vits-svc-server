What's inside

so-vits-svc is a command-line tool; this project wraps it with a web UI and task management.

Voice conversion

Upload a model and audio, submit a task; shallow diffusion (k_step) supported, progress shown in real time.

Training + resume

Drop a dataset zip into the queue. Interrupted training can resume from checkpoints; main model and diffusion both supported.

Stop and audition

Stop training mid-way to hear the result; the current checkpoint is saved as a model and ready for inference.

Loss curves

G/D losses plotted live; validation loss shown separately to judge overfitting.

Per-task cleanup

Remove data for one task only; warnings appear when other tasks could be affected.

File manager

Download or delete models, configs, results and datasets from the web UI — no SSH needed.

Pretrained assets

Upload ContentVec, NSF-HiFiGAN, base models G_0/D_0, RMVPE etc. from the web page.

Email notifications

Get notified on training completion, progress milestones, and inference completion; SMTP is configurable.

Basic hardening

CSRF protection, login rate limiting, path traversal checks, upload validation.

Rough workflow

A typical run looks like this:

Upload dataset

Zip it up; clips that are too short are skipped automatically

Queue training

Set total steps etc.; base models load automatically

Watch loss curves

Judge whether it is converging or overfitting

Stop and listen

Stop when satisfied; the checkpoint becomes a model

Train diffusion

Once the main model is done, train diffusion directly

Upload audio

Submit inference, grab the result

Getting started

Windows: install and start. Linux: integrated deploy script using Chinese mirrors.

# Install (creates venv, installs CPU/CUDA torch and dependencies)
install.bat

# Start, then open http://localhost:5000
start.bat
# Requires root; supports NVIDIA CUDA / AMD ROCm / CPU, auto-selects PyTorch
chmod +x deploy_linux.sh
sudo bash deploy_linux.sh

# Skip model downloads if the network is slow; upload later via the web UI
sudo bash deploy_linux.sh --skip-models

The script installs ffmpeg / libsndfile / cmake and other system deps, and installs Miniconda + Python 3.9 via Tsinghua / Aliyun mirrors.

Pretrained models

ContentVec and NSF-HiFiGAN are required for inference; base models G_0 / D_0 are recommended for training.

FileSizeHow to get
checkpoint_best_legacy_500.pt~180 MBDownloaded by deploy script, or upload in web UI
nsf_hifigan/model + config~54 MBSame as above
G_0.pth + D_0.pth~400 MBUpload in web UI (recommended)
rmvpe.pt etc.optionalUpload in web UI

Large files can be scp'd directly into pretrain/; the web UI picks them up automatically.
