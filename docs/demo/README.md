# 试听音频说明

落地页"听听效果"区是三轨对比播放器，当前已放置以下三个文件（整段，约 221 秒）：

| 文件名 | 内容 |
|--------|------|
| `original.mp3` | 原唱人声 |
| `converted.mp3` | 模型换声后的人声（推理结果） |
| `accompaniment.mp3` | 伴奏 |

要求：

- 三个文件用 `.mp3`（GitHub 单文件上限 100MB，mp3 约 5MB/个）
- 三轨要**同一段歌、时长一致**，这样同步播放才对得上（人声干声和伴奏本来就对齐，换声结果保持原长即可）
- 播放器会等三轨全部缓冲完成后才允许播放，避免边下边放卡顿

放好后在浏览器打开落地页试听，三轨会自动同步播放，每轨可独立调音量、静音。
