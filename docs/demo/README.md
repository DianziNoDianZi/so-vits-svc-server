# 试听音频说明

落地页"听听效果"区是三轨对比播放器，需要以下三个文件放在本目录（`docs/demo/`）：

| 文件名 | 内容 |
|--------|------|
| `original.wav` | 原唱人声 |
| `converted.wav` | 模型换声后的人声（推理结果） |
| `accompaniment.wav` | 伴奏 |

要求：

- 三个文件建议用 `.wav` 或 `.mp3`，总大小别太大（GitHub 单文件上限 100MB，建议合计 < 10MB）
- 三轨要**同一段歌、时长一致**，这样同步播放才对得上（人声干声和伴奏本来就对齐，换声结果保持原长即可）
- 如果原音频太长，先截成 20~40 秒的片段再传

放好后在浏览器打开落地页试听，三轨会自动同步播放，每轨可独立调音量、静音。
